# Mesón Asiste

Control de asistencia del Colegio Mesón: entrada y salida con huella o Face ID, ubicación, código QR, turnos
(también nocturnos), horas extra, permisos, roles configurables y reportes. Los datos se guardan en una hoja de
cálculo de Google.

## Partes del proyecto

| Carpeta | Qué es |
|---|---|
| `app/` | App de Android (Kotlin y Jetpack Compose). |
| `web/` | Versión web instalable para iPhone y cualquier teléfono. Ver [web/LEEME.md](web/LEEME.md). |
| `google-apps-script/` | Servidor: Google Apps Script con la hoja de cálculo como base de datos. |

La guía completa de instalación y configuración está en [CONFIGURACION.md](CONFIGURACION.md).
